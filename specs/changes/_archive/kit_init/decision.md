# kit_init

Kind: **evolve**. Opened 2026-09-17.

## What does init do besides copy kit files?

**[B]** Kit + skills + rules + CLI (default) + append `AGENTS.md`, **and** create empty `specs/` folders (`capabilities/`, `foundations/`, `containers/`, `components/`, `changes/`). No example capability. No system YAML.

Bootstrap still writes the first capability and `system.<name>.yaml` when the user asks.

Not A (folders left entirely to the agent). Not C (full example tree).
