# Command receipts

Class: **learn.** Speech on blast, check_sync, run, and validate. Live capability text stays until accept.

The coding agent cannot be pushed a chat message. The command prints one line that starts with `SpecPlane ·` when the result is consequential. The skills tell the agent to quote that line and to invent nothing else.

A non-empty blast has no receipt. Retrieve has none. Validate has none when there are zero errors. No line says SpecPlane caught a bug or revised the code. The agent may say it changed the implementation only by quoting a line the command printed.
