`SpecPlane_Logo.png` is the SpecPlane mark: four stacked planes labeled **AI**, **API**, **UX/UI**, and **KPI**, with **SpecPlane** on the top plane and an arrow along the shared normal.

The same file also lives at the repository root as [`SpecPlane_Logo.png`](../SpecPlane_Logo.png) for the README and the historical GitHub raw URL.
