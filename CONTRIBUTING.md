# Contributing

Pull requests go against `main`. Do not push to `main`.

Do not copy this repo’s `specs/` into other apps. That tree is SpecPlane specifying its own CLI.

Product changes follow the `specplane-implement` skill and [`docs/golden-journey.md`](docs/golden-journey.md). Do not slurp `specs/`.

`.cursor/skills` and `.agents/skills` stay identical.

`design-docs/` is local strategy. Do not commit it.

By contributing you agree the work is under Apache 2.0. There is no CLA.

Bugs go to [GitHub Issues](https://github.com/gauravbaruah/SpecPlane/issues). Do not use Discussions for bugs until we say so.
