# Contributing

Pull requests are welcome against `main`. Please do not push directly to `main`.

`specplane init` creates a `specs/` directory in your project. The `specs/` directory in this repository specifies SpecPlane's own CLI. There is no need to copy these specs into your project.

For a product change, please follow the `specplane-implement` skill and [`docs/golden-journey.md`](docs/golden-journey.md). Please do not slurp `specs/`.

Please keep `.cursor/skills` and `.agents/skills` identical.

`design-docs/` is local strategy. Please do not commit it.

By contributing you agree the work is under Apache 2.0. There is no CLA.

Please file bugs on [GitHub Issues](https://github.com/gauravbaruah/SpecPlane/issues). Please do not use Discussions for bugs until we say so.
